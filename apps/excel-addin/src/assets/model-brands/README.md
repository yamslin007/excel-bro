# Model vendor marks

Local SVG assets from Lobe Icons `@lobehub/icons-static-svg@1.102.0`:
https://github.com/lobehub/lobe-icons

Source URL: `https://unpkg.com/@lobehub/icons-static-svg@1.102.0/icons/<name>.svg`.
The upstream MIT license is included in LICENSE. Brand marks remain the property
of their respective owners and are used only to identify configured model families.
Assets are bundled locally; rendering makes no external network requests.
CSS masks preserve the vendor shapes while following light/dark theme text color.
