# 工作日志 2026-08-25

## 主题：计划编辑器（编辑执行脚本）UI 改版与交互优化

### 背景

用户反馈"编辑执行脚本"页面设计粗糙：深色 JSON 块与整体 Notion 浅色主题割裂、
两栏对半切布局生硬、JSON 编辑停留在裸 textarea（无高亮/行号/实时校验）、
状态反馈缺失且部分文案误导（聊天中也显示"校验中…"）、忙碌态无提示、
离开无未保存确认等。先做了可交互静态 mockup 供确认方向，确认后落地到真实组件。

## 实施内容

### 1. 共享 JSON 编辑器组件

**新增文件：**
- `apps/excel-addin/src/components/JsonCodeEditor.tsx`
- `apps/excel-addin/src/components/JsonCodeEditor.test.ts`（6 个测试）

**功能：**
- 语法高亮：key/字符串/数字/布尔/null 分色（textarea + 底层 `<pre>` 叠加，未引入
  Monaco / CodeMirror，避免包体积翻倍）
- 固定行号（错误定位直接指向第几行）
- 编辑时本地实时校验：格式错误立即定位到行/列，错误条悬浮在代码区上方（不占布局）
- 复制、格式化按钮；浅色/深色代码皮肤（浅色跟随主题 CSS 变量，偏好存 localStorage）
- 底部状态栏：光标行列、是否已修改

### 2. 独立窗口 PlanEditorDialog 重构

**修改文件：** `apps/excel-addin/src/components/PlanEditorDialog.tsx`

**改动：**
- 头部：关闭按钮、标题、面包屑（工具/消息 + 计划标题 + 动作数）、「已修改」徽标
- AI 对话侧栏：带头像的气泡消息、示例需求 chips（后按用户要求移除）、
  AI 思考三点动画、可折叠成窄侧栏、分隔条可拖动宽度
- JSON 区改用共享 `JsonCodeEditor`
- Ctrl+S 保存、Esc 关闭确认弹窗；未保存修改离开时弹确认
- 加载态 spinner；错误提示分层（本地语法错误就地显示，结构校验/AI 失败显示在顶部）
- 发送按钮在输入区垂直居中

### 3. 任务窗格抽屉 PlanJsonEditor 重构

**修改文件：** `apps/excel-addin/src/components/PlanJsonEditor.tsx`

与独立窗口共用 `JsonCodeEditor`，保持两种形态一致；补齐「已修改」标记与 Ctrl+S。

### 4. 保存流程调整（用户明确要求"快"）

**修改文件：** `apps/excel-addin/src/components/PlanEditorDialog.tsx`、
`apps/excel-addin/src/hooks/usePlanEditor.ts`

- 移除保存时的服务端 `validatePlan` 调用，只做本地 `JSON.parse` +
  `assertEditablePlan`（白名单结构）检查，保存不再有"校验中…"等待
- **已确认的取舍**：跳过服务端规范化后，保存的计划不再自动重算验收条件
  （acceptanceCriteria），执行后的自动验证可能缺失或降级
- Ctrl+S：快捷保存，弹出"已保存"提示，窗口保持打开可继续编辑
- 「保存」按钮：保存后直接关闭窗口
- 父窗口收到保存消息后不再主动关闭对话框（`App.tsx`），由子窗口自行关闭

### 5. 样式与布局修复

**修改文件：** `apps/excel-addin/src/styles.css`

- 新增 `.json-editor-*` 代码编辑器样式，全部走 CSS 变量、跟随主题预设；
  `.json-editor.skin-dark` 提供固定暗色
- 修复清空 JSON 后编辑区高度塌缩：
  - 对话框网格改为 `auto minmax(0,1fr)` + 显式 `grid-row`，编辑区始终占满剩余高度
  - 工具栏单行不换行、按钮固定宽度不收缩，状态文字超长省略，避免状态文字变化
    导致工具栏/代码区高度跳动
- 移除不再使用的 `.plan-editor-button-spinner`、`.plan-editor-shortcut` 等样式

### 6. 文档与文案同步

- 更新 `docs/AI_PLAN_EDITOR.md`、`docs/PLAN_EDITOR_DIALOG.md`
- 更新界面可见文案：抽屉副标题改为"保存前会检查 JSON 格式与白名单结构"，
  App 工具详情说明同步；移除界面上的 "Ctrl+S 保存" 提示（快捷键保留，不显示）

## 技术亮点

1. **零依赖语法高亮**：textarea + `<pre>` 叠加渲染 + 轻量 tokenizer，
   几十行 JSON 的编辑场景收益撑得起成本，不引入 Monaco/CodeMirror
2. **布局稳定性**：通过显式 grid 行 + 单行工具栏，彻底消除"内容多少导致
   编辑区高度跳动"的布局漂移
3. **双形态共用组件**：独立窗口与任务窗格抽屉共用 `JsonCodeEditor`，
   样式与行为保持一致
4. **主题一体化**：代码区颜色全部改为 CSS 变量，随 4 套主题预设切换，
   不再有硬编码暗色块

### 实施内容

**主题一体化（P0）：**
- 工具区硬编码灰绿色全部替换为 CSS 变量（新增 `--color-warning-*`、
  `--color-danger-*`），随 4 套主题预设切换：工具箱选择器、工具列表、
  参数卡片、输入框、待处理高亮、保存审查 issue 等

  新增 `highlightToolDsl`（`toolDsl.ts`）做 DSL 语法高亮（关键字/参数名/
  字符串/矩阵标签/布尔/数字分色），新增 3 个测试
  - 按用户反馈，只读脚本块固定使用深色代码皮肤（保留语法高亮），
    编辑器内的 JSON 编辑区仍可切换浅/深皮肤

**流程与状态反馈（P1）：**
- 运行工具三步指南的状态徽标统一语义：第 1 步随工作表选择变为
  「待处理/已完成」（固定来源时显示「固定来源」），第 3 步随字段完成度

- 「使用这个工具」「运行这个查询」按钮增加加载反馈（spinner +
  「正在读取工作簿…」「正在运行…」），期间禁用重复点击
- 查询工具卡片 meta「模型调用 0 次」改为「本地确定性执行」

**细节（P2）：**

  可点击直接切换到专家视图（查询工具无此入口）
- 专家视图「编辑脚本」按钮移到与「复制脚本」同一行
- 计划编辑器页面配色统一：状态"有效"绿点改用品牌绿变量（原来混用
  `#2f9e6e` 和 `#2f6b47` 两种绿），错误提示的红色统一改用 `--color-danger-*` 变量
