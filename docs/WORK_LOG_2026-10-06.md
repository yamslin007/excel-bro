## 一、核心问题识别

### 当前 SDK 集成的问题

```python
# server/app/claude_sdk_agent.py (第 74-76 行)

tools=[],  # ❌ 空的！所有工具被禁用
disallowed_tools=["Read", "Bash", "Write", ...],  # ❌ 全部禁用
allowed_tools=["mcp__excel_bro__submit_*"],  # ❌ 只能立即提交
```

**结果：**
- Agent 无法探索数据
- 无法运行 Python 分析
- 被迫一次性生成计划 → 准确率低
- 付出了 SDK 的复杂度但没获得灵活性

---

## 二、解决方案设计

### 核心思路

```
释放 SDK 的探索能力
     ↓
通过 MCP 工具守卫最终写入
     ↓
保留白名单 + 预览 + 恢复点
```

### 双宿主架构（Excel + WPS）

```
┌────────────────────────────────────────┐
│  前端 (React)                           │
│  ├─ Excel Add-in (Office.js)           │
│  │   → readSheetDataOffice()           │
│  └─ WPS Add-in (WPS JSAPI)             │
│      → readSheetDataWps()              │
└──────────────┬─────────────────────────┘
               │ HTTP (携带数据快照)
               ▼
┌────────────────────────────────────────┐
│  FastAPI Backend                        │
│  └─ request.sheetsData[sheet_name]     │
│     (双宿主通用，无需区分)              │
└──────────────┬─────────────────────────┘
               │
               ▼
┌────────────────────────────────────────┐
│  Claude Agent SDK                       │
│  ├─ Read (临时文件)                     │
│  ├─ Bash (Python 分析)                  │
│  └─ MCP 工具 (受控 Excel 访问)         │
└────────────────────────────────────────┘
```

### 三层安全防护

```
第一层：授权层
  → MCP 工具只能读已授权的表
  → if sheet_name not in authorized: return error

第二层：白名单层
  → submit_plan 只接受合法动作
  → ALLOWED_ACTIONS = ["writeValues", "writeFormulas", ...]

第三层：确认层
  → 用户预览计划后才执行
  → 可以撤销操作
```

## 四、关键改进点

### 1. 工具释放

```python
# 改造前
tools=[],
disallowed_tools=[所有工具],

# 改造后
tools=["Read", "Bash"],
allowed_tools=["Read", "Bash", "mcp__excel_bro__*"],
```

### 2. 数据读取（双宿主）

```typescript
// Excel (Office.js)
const data = await readSheetDataOffice(sheetName);

// WPS (JSAPI)
const data = await readSheetDataWps(sheetName);

// 两者格式统一
[{"产品": "A", "销量": 100}, {"产品": "B", "销量": 200}]

// 后端无需区分
data = request.sheetsData[sheet_name]
```

### 3. MCP 工具守卫

```python
async def read_authorized_sheet(sheet_name: str):
    # 1. 验证授权
    if sheet_name not in authorized_sheets:
        return error
    
    # 2. 从请求读取
    data = request.sheetsData[sheet_name]
    
    # 3. 返回 JSON
    return {"data": data}

async def submit_plan(plan: dict):
    # 1. 白名单校验
    validate_plan(plan)
    
    # 2. 设置终结状态
    terminal = AssistantResponse(kind="plan", plan=plan)
    
    # 3. 用户确认
    return "等待用户预览"
```

### 4. 超时延长

- **会话：** 30分钟 → 24小时
- **Agent：** 1分钟 → 10分钟
- **规划：** 5分钟 → 30分钟
