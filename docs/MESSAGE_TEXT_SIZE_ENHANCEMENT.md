# 消息界面体验优化方案

> **背景**：用户提到"看看模型接入后的对话这里"，检查发现消息文本字号偏小，可读性有提升空间。

---

## 📋 问题分析

### 当前状态

**消息文本样式**（`styles.css:2833-2843`）：

```css
.message-text {
  margin: 0;
  border: 0;
  background: transparent;
  color: #27352c;
  padding: 0;
  font-size: var(--font-size-caption);  /* 12px */
  line-height: 1.62;
  white-space: pre-wrap;
  box-shadow: none;
}
```

### 存在的问题

1. **字号过小**
   - 当前使用 `--font-size-caption`（12px）
   - 对于主要内容文本来说偏小，影响阅读体验
   - 特别是 AI 返回的较长回复时，12px 字号阅读疲劳

2. **与设计系统不匹配**
   - 项目定义了字号阶梯：caption(12px) < body(14px) < subtitle(16px) < title(20px)
   - 消息正文作为主要内容，应使用 body 级别（14px）
   - caption 应该用于次要信息（如时间戳、元数据）

3. **对比其他元素**
   - 消息作者标签：12px（`--font-size-caption`）✅ 合理
   - 消息正文：12px（`--font-size-caption`）❌ 偏小
   - 按钮文字、输入框：14px（`--font-size-body`）✅ 合理

---

## 🎯 优化方案

### 1. 提升消息正文字号

**改动**：将 `.message-text` 的字号从 `--font-size-caption`（12px）改为 `--font-size-body`（14px）

**位置**：`apps/excel-addin/src/styles.css:2839`

**修改前**：
```css
.message-text {
  font-size: var(--font-size-caption);  /* 12px */
  line-height: 1.62;
}
```

**修改后**：
```css
.message-text {
  font-size: var(--font-size-body);  /* 14px */
  line-height: 1.62;  /* 保持不变，14px × 1.62 ≈ 22.68px */
}
```

---

### 2. 相关元素检查

需要确认其他消息相关元素的字号是否需要同步调整：

| 元素 | 当前字号 | 是否调整 | 理由 |
|------|---------|---------|------|
| `.message-author` | 12px (caption) | 否 ⛔ | 作者标签是次要信息，保持小字号合理 |
| `.message-author em` | 12px (caption) | 否 ⛔ | 模式标签是辅助标识，保持小字号 |
| `.message-text` | 12px (caption) | **是 ✅** | **主要内容，应提升到 body 级别** |
| `.user .message-text` | 12px (caption) | **是 ✅** | **继承 `.message-text`，自动提升** |
| `.message-attachments span` | 12px (caption) | 否 ⛔ | 附件名称是次要信息，保持小字号 |
| 计划卡片文字 | 各不相同 | 否 ⛔ | 保持现有设计 |

**结论**：只需修改 `.message-text` 一处，用户和助手消息会自动继承。

---

### 3. 行高计算验证

**当前行高**：`1.62`

**修改前**：12px × 1.62 ≈ 19.44px  
**修改后**：14px × 1.62 ≈ 22.68px

**对比 Fluent 规范**：
- Body 推荐行高：20px（紧凑）~ 24px（舒适）
- 22.68px 位于推荐区间内 ✅

**结论**：行高 `1.62` 保持不变。
