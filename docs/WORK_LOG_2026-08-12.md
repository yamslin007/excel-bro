# Excel Bro - 2026-08-12 工作记录

## 🎯 主题：安全加固（公式护栏 / 移除任意代码执行 / Origin 白名单）+ App.tsx 大拆分

昨天的改动分两条线：一条是**安全加固**（针对单机个人工具但接口无鉴权的威胁模型），另一条是**拆掉 6907 行的 App.tsx 单文件维护性债务**。

---

## 阶段 1：公式安全护栏（前后端镜像）

### 前端 `formulaSafety.ts` + `formulaSafety.test.ts`
镜像 `server/app/safety.py` 的校验逻辑，写入工作簿前拦截危险公式：
- **危险函数黑名单**：`WEBSERVICE`、`HYPERLINK`、`IMPORTXML`、`IMPORTDATA`、`IMPORTHTML`、`FILTERXML`、`EXEC`、`CALL`、`REGISTER`。
- **注入载体**：`DDE`（`=cmd|...`）、`UNC` 前缀（`\\`）、外部工作簿引用（`[...xlsx]`）、超链接地址的 `=`/`file:`/网络前缀。
- 导出 `dangerousFormula` / `dangerousHyperlinkAddress` / `assertSafeFormula` / `assertSafeHyperlink`。
- `config/capabilities.json` 新增 `safety.allowHyperlink`（默认 `false`，配置开关控制 HYPERLINK 是否放行）。

### 服务端
- `capabilities.py` 新增 `capability_bool()`：读布尔开关，缺失取安全默认 `False`，存在但非 bool 时报错。
- `rule_generator.py`：`/api/formulas/generate` 生成公式后先过 `dangerous_formula`，命中即抛 `ValueError` 拒绝写入。
- `folder_workbooks.py` 新增 `_force_text_if_formula()`：**值路径公式注入防护**——openpyxl 会把以 `=` 开头的字符串当公式写入（`data_type='f'`），对值单元格加前导撇号强制按文本存储；`rangeEquals` 验收比较时同步按此处理，避免「值写入=公式」路径被注入。

## 阶段 2：移除用户自定义规则执行（任意代码执行隐患）

`apps/excel-addin/src/functions/functions.ts`：删除 `new Function('return ' + rule.compiled)()` 求值分支——该分支是**任意代码执行入口**，且规则系统已收缩为「仅内置预制规则」，用户自定义规则成为不可达死代码。现在非预制规则直接抛错，不再执行编译字符串。

---

## 阶段 3：服务端 Origin 白名单中间件

`server/app/main.py`：
- 新增 `ALLOWED_ORIGINS` 白名单（localhost / 127.0.0.1 的 3000 端口）+ CORS 配置。
- 新增 `guard_state_changing_origins` 中间件：对 `POST`/`PUT`/`DELETE` 校验 `Origin` 头，不在白名单即返回 `403 FORBIDDEN_ORIGIN`。
- 动机：本地 API 无鉴权，CORS 只限制浏览器「读取」响应、不阻止「发出」请求，恶意网页可用简单请求改配置/删连接/弹文件夹对话框；带 Origin 的浏览器跨站请求必须校验，不带 Origin 的本机脚本/安装器放行。

## 阶段 4：App.tsx 拆分（6907 行 → 4016 行）

单文件拆分，**只拆纯函数 + 渲染 JSX，业务逻辑函数全部留在 App**，逻辑不动、闭包语义不变，风险可控；`tsc` strict 模式兜底 prop 接线错误。

- **Stage A 纯函数/常量** → `conversation.ts`(270)、`format.ts`(130)、`intent.ts`(148)、`range.ts`(54)、`utils.ts`(94)。
- **Stage B 渲染 JSX** → 8 个组件：`ChatHeader`、`SettingsDrawer`、`ToolDrawer`、`HistoryDrawer`、`ConfirmDialogs`、`ScopePopover`、`Composer`、`MessageItem`（全部扁平放 `src/`，匹配现有约定）。
- 依赖单向：`App → 组件 → 工具函数`，组件绝不 import App（防环）。
- 测试导入同步更新（`chatHistory.test.ts` 等）；JSX 正确性靠 `tsc` + 人工冒烟。
