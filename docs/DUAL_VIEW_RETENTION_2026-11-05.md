# 双视图前态与副本保留

## 行为与范围

Excel 原先只把修改区域前值装入新工作簿，周边标题和内容缺失，看起来像拿空白表比对。现在保存授权目标表已用区域与写入区域的并集，副本展示当时的单元格值、基础格式、行列尺寸和合并区域。公式使用缓存值，不重新计算。不是完整工作簿克隆：图表、条件格式、表对象、隐藏行列等复杂语义未实现历史还原，打开时明确提示。

WPS 保留原生整表复制，并补充写前单元格快照及可读取基础格式/列宽，避免打开时才复制当前表导致内容漂移。图表等复杂对象仍来自打开时原表，不声称是历史快照。旧 WPS 材料只有动作范围时显示局部前态限制；Excel 中断/旧记录没有整表快照时拒绝制造空白前态副本。

退出双视图保留副本，切表后返回复用；确认只接受结果，放弃使用已验证恢复点，二者成功且落账后才收尾。清理失败不改变业务结果。Excel 关闭前保留本机恢复归档，归档不随临时副本关闭删除。WPS 内容检查覆盖已用单元格及已采集格式；复杂对象的额外编辑检测仍有局限，不能宣称任意对象编辑均可检测。

## 持久化与启动

- IndexedDB 记录仅在本机，按宿主、工作簿身份、执行 ID 和授权表集合绑定，不向模型传数据。展示快照不参与恢复写入。
- 单目标快照最多 20,000 格，单条持久化记录最多 8 MB，沿用 capabilities 配置。存储失败明确提示刷新限制。
- 刷新前端可认领同一宿主中尚存副本；人工关闭或完整退出宿主后，不保证原窗口存在。身份冲突保留待审阅，不制造未经核实窗口。
- 重启后端以启用 `/api/office/review-layout/suspend` 与 `/resume`，再刷新前端。后端重启丢失原生布局缓存，多个遗留窗口可能需要手动排列；不绕过身份校验。
