## 真实 WPS 验收

用户在 WPS 表格个人版 12.1.0.28488 提供的实测截图已经确认：

- [x] 初始验证版本的功能区出现 Excel Bro 标签。曾为减少独立功能区空白将入口移入
  “开始”标签；后来发现会挤占原有按钮空间，现已改回独立标签，改回后的真实宿主显示待复核。
- [ ] 点击独立标签中的“打开 Excel Bro”后，任务窗格显示且自动切回“开始”；
  宿主不支持切换时仍需确认任务窗格可用。
- [x] 点击“打开 Excel Bro”后显示任务窗格。
- [x] 任务窗格显示“WPS 表格连接成功”。
- [x] 工作簿名称、活动工作表、工作表数量和选区内容与当前文档一致。
- [x] 官方开发登记能够在目标个人版中加载。

截图同时发现 WPS 的 Range.Address 是方法而不是普通属性，旧探测页因此显示了函数文本。
实现已按官方接口改为调用 Address()，并增加自动化回归；刷新后的真实地址仍需复核。

以下生命周期边界仍待人工验证：

- [ ] 当前选区地址显示为真实 A1 地址，不再显示函数文本。
- [ ] 再次点击功能区按钮能够显示现有窗格，不重复创建失控窗格。
- [ ] 关闭窗格后可以再次打开。
- [ ] 停用或移除开发加载项后入口消失，其他 WPS 加载项不受影响。

W0 的核心加载与只读桥接已经通过；上述生命周期项目继续作为发布前验收项。W1/W2
的授权读取和只读 Agent 接入不得用本记录中的构建成功代替真实宿主验收。
