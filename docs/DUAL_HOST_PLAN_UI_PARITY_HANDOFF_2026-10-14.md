## 交给 DeepSeek 的执行要求

请在当前工作树接手并完成这些问题。先读 `docs/ARCHITECTURE.md`、`docs/DEVELOPMENT.md` 和本文件。大量未提交变更属于之前工作，不能重置或覆盖。无需完成一个小项就询问，统一交付。

### 1. 对齐计划卡和审阅交互

- 共用计划展示组件或展示模型，避免再次维护两套语义。两端都有：标题、授权目标、动作与规模、实际改动摘要、编辑计划、取消、生成副本、审阅状态、确认写回、放弃。
- 决策需要的实际改动首屏可见；技术详情可折叠。格式动作显示字体/对齐/尺寸变化，不能伪装成值写入。
- 已写回或已放弃的旧卡降级为结果说明，不能继续显示“准备就绪”与可再次提交的按钮。
- 统一通用操作名称。WPS 的副本方位、Excel 的兼容副本人工确认与无法自动回读等宿主差异如实说明，不强行伪装相同能力。
- 保留 Excel 兼容模式人工核对勾选条件、WPS 实际副本核对、原表变化检查；不能为了统一 UI 绕过任何条件。
- 与用户已验收的结果卡、卡内撤销、恢复身份匹配兼容。

### 2. 统一运行中的主题色

- 修改 Excel `.send-button.is-stop` 的中性灰底，发送/暂停都用当前主题令牌。
- 建议将共同按钮状态样式集中，WPS 不再靠独有覆盖才能正确。
- 保持暂停、输入补充后转向、忙碌时防重复提交的现有行为，不能把真正禁用控件也伪装成可点击。
- 检查各已有主题及键盘焦点；运行中的可点击暂停按钮与禁用按钮必须能区分。

### 3. 计划编辑能力与名称对齐

- 把 Excel 消息卡、已保存工具、编辑器标题及帮助里的“编辑脚本/执行脚本/计划脚本”统一为清晰的“编辑计划/计划 JSON”等术语。
- 共享 JSON 编辑与错误展示语义；Office.js 弹窗和 WPS 网页呈现属于宿主适配，不能把 Office 专属弹窗 API 强接到 WPS。
- 修改计划后重新做授权、白名单、属性子集、限额、来源与目标检查，并生成新预览；旧副本和旧验证状态失效，重新确认后才能写入。
- 确认本地结果引用计划仍保留服务端归属与编译校验，不能让编辑入口绕过结果引用限制。

### 4. 补齐 WPS 保存和编辑个人工具

- 接通“验证后保存 → 我的工具 → 编辑计划模板 → 使用工具 → 当前授权下重新校验与预览 → 用户确认”。
- 共用 `SavedTool`、存储与模板语义；WPS 实例化后必须走 WPS 当前能力白名单与属性限制，不能照抄 Excel 整体可执行动作集。
- 保存资格绑定实际已验证的计划版本/执行身份，不能只因同 planId 的旧版本验证通过就放行已修改版本；失败、部分完成、未验证的计划不得冒充验证后工具。
- 无当前数据读取依据时保留已有工具来源/schema 核对，不把历史授权带入新工作簿，不保存凭据或不必要的原始数据副本。
- 补已保存工具的模板编辑入口；检查删除等已有 Excel 工具管理操作是否在 WPS 缺失，按相同用户任务补齐，并逐项报告。
- 两端不同页面来源的存储是否共享应按实际情况说明；相同工具能力不等于可以假定 localStorage 跨来源同步。

### 5. 实际宿主动作能力单列

当前 `config/capabilities.json` 的 WPS 写入只开放 `writeValues`、`writeFormulas`、`clearRange:contents`、`setFont`、`setAlignment`、`resizeRange`，格式属性还有子集限制；Excel 更多动作确实不等价。

请用当前代码维护按用户任务的能力差距表，区分已实现、未实现、宿主限制、实机待验。此轮先打通上述计划编辑/个人工具任务及交互；其余格式与结构动作列后续实施顺序，不通过修改配置把未实现项写成已支持，也不删除 Excel 能力来掩盖差距。

## 验证与交付

- 有行为判别力的两端面板测试：相同请求生成相同语义的计划摘要；编辑后旧副本失效；验证后能保存并重用工具；未验证/修改版本不能保存为已验证工具；越权/未支持属性被拒；暂停按钮触发原动作。
- 运行 `test:addin`、`test:wps`、`build:addin`、`build:wps`。若改共享协议，同步 TS/Pydantic 并运行相关服务端检查；提交前按 AGENTS 运行全部规定检查。
- 300px、430px 和宽窗格核对首屏、长说明、长按钮、运行状态与不同主题。静态 CSS 检查不能冒充浏览器视觉或真实宿主验收。
- 明确保留之前用户已确认通过的双端消息结果卡/格式执行/撤销实机证据；新改动单列实机未复验，不能把整个项目重新写成“从未实机验收”。
- 汇报每个问题的改动、测试、剩余差距和最短双端验收步骤；不提交、不推送、不发布、不操作业务工作簿。
