# 输入框 EB 菜单（2026-11-03）

EB 品牌图标由顶部移到输入框左下角，替换图片按钮。点击展开工具、宠物、壁纸、EB 函数、专注窗口；加宽窗格留在分隔线后的次要区域。顶部栏、标题和相关长按彩蛋均移除；底部按「新对话 → 备份恢复 → 历史记录 → 文件选择」排列。备份恢复换为实心左回转箭头，仍打开原恢复界面，不直接撤销；历史记录沿用原处理器。模型加载/断连等状态提示移到输入区。壁纸保留为普通菜单功能。

两端共用 ComposerAppMenu，菜单向上展开、限高自滚，支持点击外部、失焦和 Escape 关闭及方向键选择。普通输入时位于模型选择左侧；审阅/恢复占用输入区时保留独立的左下角入口。去掉图片选择按钮，粘贴/拖入图片、视觉模型与隐私约束保持原样。
