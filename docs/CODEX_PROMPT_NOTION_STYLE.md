# Codex 任务：实施 Notion 风格视觉优化

## 任务概述

阅读 `docs/NOTION_STYLE_MIGRATION.md` 中的完整设计方案，按照其中的规范对 Excel Bro 插件进行视觉优化。

## 目标

在保持 Fluent Design 基础架构和所有现有功能的前提下，借鉴 Notion 的视觉风格，提升界面精致度和用户体验。

## 实施要求

### 1. 分阶段实施（按优先级）

**阶段 1：基础色彩和圆角**（最高优先级）
- 在 `apps/excel-addin/src/styles.css` 顶部添加新的 CSS 变量（色彩、圆角、间距、阴影）
- 全局搜索并替换旧的硬编码色值为新变量引用
- 统一圆角：按钮/输入框/列表项 → 8px，标签 → 4px，头像/格仔 → 50%
- 特别注意：格仔（宠物乌龟🐢）必须保持圆形（50%），不能改成 8px

**阶段 2：悬停态和动画**（高优先级）
- 为所有列表项（工具列表、工作表列表、模型列表）添加 Notion 式悬停态：`background: rgba(0,0,0,0.03)`
- 为按钮添加悬停上浮动画：`transform: translateY(-1px)`，过渡时间 `150ms ease`
- 为输入框添加聚焦态：绿色边框 + 绿色阴影环

**阶段 3：细节打磨**（中优先级）
- 检查并统一图标线条粗细（`stroke-width="1.5"`）和尺寸（16px/20px）
- 确保所有间距使用 `var(--spacing-*)` 变量，不要硬编码
- 检查卡片、抽屉等组件的圆角和阴影

### 2. 关键约束

**必须保持的元素**：
- ✅ 格仔（宠物乌龟）必须保持圆形且可见
- ✅ 所有现有功能不能受影响
- ✅ 色彩对比度必须符合 WCAG AA 标准
- ✅ 键盘导航和可访问性不能降低

**禁止的操作**：
- ❌ 不要使用厚重的 Material Design 阴影
- ❌ 不要把所有圆角都改成 999px 或直角
- ❌ 不要删除或隐藏格仔
- ❌ 不要破坏现有的功能逻辑

### 3. 测试要求

每个阶段完成后，必须：
1. 运行 `npm run build:addin` 确保构建通过
2. 运行 `npm run lint` 确保代码规范通过
3. 运行 `npm run test:addin` 确保测试通过
4. 手动测试主要交互场景（发送消息、选择工作表、打开工具抽屉）

### 4. 参考文件

完整设计方案：`docs/NOTION_STYLE_MIGRATION.md`
- 包含所有色彩色值、圆角规范、间距系统
- 包含具体的 CSS 代码示例
- 包含改动前后的对比说明

## 输出要求

1. **分阶段实施**：完成一个阶段后，运行测试，确认无误后再进入下一阶段
2. **改动说明**：每个阶段完成后，简要说明改动了哪些文件、哪些样式
3. **视觉验证**：说明如何验证新样式是否生效（如"消息气泡圆角从胶囊形变成 8px"）
4. **问题报告**：如果遇到无法解决的冲突或问题，立即报告，不要强行继续

## 提交规范

每个阶段完成后创建一次 commit：
- 阶段 1：`style: 迁移到 Notion 风格色彩和圆角系统`
- 阶段 2：`style: 添加 Notion 风格悬停态和交互动画`
- 阶段 3：`style: 统一图标和间距以完成 Notion 风格迁移`

## 开始实施

请按照 `docs/NOTION_STYLE_MIGRATION.md` 中的方案，从阶段 1 开始实施。完成每个阶段后报告进度，等待确认后再继续下一阶段。
