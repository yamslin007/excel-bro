# WPS W2 只读 Agent 验证记录（2026-09-22）

## 已实现

- WPS 任务窗格从现有本地服务读取模型目录并允许选择已配置模型。
- 提交问题时重新绑定当前工作簿和明确勾选的工作表。
- 完整单元格数据仅由 WPS 宿主读取并交给现有 query_table 确定性引擎。
- 意图请求仅包含工作簿/工作表元数据、字段名和尺寸，不包含原始数据行。
- 最终回答请求仅包含结构空壳和 query_table 的紧凑结果。
- 支持意图澄清选项、查询进度、停止、文本回答和表格结果。
- 模型返回 AnalysisPlan 时由 WPS 响应出口硬拦截，不显示执行确认，也不调用任何写入 API。
- WPS 界面明确标注写入、删除、拆表、撤销和恢复均未开放。
- 本地服务来源白名单仅增加开发地址 http://localhost:3889 与
  http://127.0.0.1:3889，没有放开通配来源。

当前实现复用 apps/excel-addin/src/dataTools.ts 的纯确定性计算入口。WPS 构建只引用
Office.js 类型声明以编译该共享模块，不加载 Office.js 脚本，也不调用 Excel.run。
后续可把纯查询核心下沉到独立共享目录，减少宿主模块之间的源码依赖。
