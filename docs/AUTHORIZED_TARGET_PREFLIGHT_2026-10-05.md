# 授权目标前置确认（Excel / WPS）

## 已实现

- 共享 `checkAuthorizedTarget` 与 `useAuthorizedTarget`：首次成功获取当前授权元数据作为当前窗格内的检测基线。路径、引用只驻留内存，不送模型、不进入聊天历史；界面只展示文件名和工作表。
- 窗格可见且空闲时每 2 秒检查身份元数据（`config/capabilities.json: authorizedTarget.monitorIntervalMs`）；focus / visibilitychange 也触发检查。只读取文件身份、工作表标识/名称，不读取单元格、表头、UsedRange 或数据行。隐藏、分析/写入中、已有确认弹窗、已有审阅副本时暂停后台监测。
- 发送、澄清提交、本地映射、保存查询/工作流、预览/写入/编辑、恢复、函数操作等入口先检查。WPS 模型等待后的源数据读取与预览准备再次检查；Excel 模型响应与本地映射/规划恢复同样检查。
- 检测到正面变化先弹确认卡，暂停后续操作，不作为任务失败；证据不足显示“需要重新确认操作目标”，不谎称文件已变化。目标单选和工作表复选均无默认选择。
- 可选择切回原授权，或改用当前文件并显式勾选工作表。点击确认重新读取元数据，不复用点击前尚在进行的检查；期间再变化则拒绝确认。勾选不构成授权，确认不构成写入批准。
- 确认被拒后重试保留用户已做的选择：notice 带稳定 `round`，只有真正的新一轮确认才递增；仅文件身份变化才开新一轮（比较时忽略 `selected`，避免用旧勾选误判）。被拒重试若重新读取的目标缺少某些工作表，只丢弃这些失效 id，其余勾选与单选保留。
- 保留输入和语义确认；新目标不能套用旧文件私有映射/待执行预览。旧操作不会自动重放：只对被拦下的首次文本发送提供确认后重新发起；其他入口需显式再次点击或重新生成预览。
- 有活跃审阅副本时禁止切换任务授权。WPS 仅对已正面识别的本次副本豁免审阅操作；任意其他活动文件不豁免。后台监测不把生成副本当作新的原表。原有原表/副本身份、源/目标快照和写前授权守卫保留。

## 能力边界

- 这是前置变化检测与确认入口，不是强身份系统重写：同路径文件替换、WPS 同索引同名工作表替换，无法仅凭本层元数据证明，仍由原有快照/身份/写入守卫拒绝不确定现场。
- 未实现：授权基线跨窗格关闭的耐久身份恢复；未保存文件的新包装对象强身份证明；跨关闭私有映射恢复；CAP-03 精确动作续跑。不得标成“待实机验收”。
- Office.js 检查的是加载项所在文档，不是任意全局活动 Excel 窗口。WPS 检查 ActiveWorkbook。两者按授权语义对齐，不伪造相同宿主机制。
- 未接新增原生文件激活事件：后台元数据监测用于补足事件缺口，不能承诺切换瞬间同步弹窗；操作入口检查不依赖轮询时机。
- openpyxl 文件夹模式不使用窗格活动文件检测，既有文件选择、目录授权、预览和确认不变；本轮无服务端协议变更。

## 自动化与实机验收

自动化覆盖：同名异路径、表改名/移除/授权变化、身份不可读取、未授权新表不扩权；无 focus 的操作前检查、2 秒主动提示且不会清空正在勾选的弹窗；确认期间再次切换、确认不复用旧检查；取消保留输入、原授权必须切回、阻断旧写入不自动重放；WPS 实际点击重新选目标后才调用模型；模型等待期间变更导致源数据读取为 0；Excel 审阅生成与保存入口拒绝检查时调用次数为 0。

真实宿主待验（只用独立测试工作簿）：

1. 空闲时切换 WPS 文件 / Excel 授权工作表，观察确认卡先于下一操作出现；选择当前文件并勾选一张表，确认后才生成新预览。
2. 弹窗开着再切另一文件，确认应拒绝；取消后原输入保持。
3. 审阅副本并排打开不触发重新授权；切换无关文件不能保存到它。
4. 模型分析期间切换 WPS 文件，读取前暂停；窄窗格下单选、复选、确认/取消可见，Tab 焦点留在弹窗，Esc 可取消。
