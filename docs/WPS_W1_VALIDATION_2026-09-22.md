# WPS W1 授权读取验证记录（2026-09-22）

## 实施范围

- 当前工作簿和工作表元数据读取。
- 明确勾选工作表后生成本次读取授权；空选择不自动回退到当前表或全部表。
- 绑定工作簿名称、完整路径/会话引用，以及工作表序号和名称。
- 使用 UsedRange、Range.Item、Worksheet.Range 和 Value2 分块只读。
- 每个分块前复核工作簿身份、工作表身份和使用区域尺寸。
- 支持读取进度、停止、结果行列数和前 5 行本地预览。
- WPS 当前仍不开放任何 AnalysisPlan 写入、撤销、恢复或自定义函数。

读取限额集中在 config/capabilities.json 的 wpsRead：

- chunkRows：500
- maxRows：250000
- maxColumns：100
- maxCells：1000000

这些是首轮安全值，不代表目标 WPS 版本的最终性能上限；真实大表测试后再调整。
