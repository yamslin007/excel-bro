# 统一范围选择器与选中即校验

## 改动

截图中的冗余来自两个授权入口：底部数据范围选择器和上层目标确认弹窗。正式 Excel/WPS 入口统一使用原选择器；授权守卫只提供非模态状态和跳转入口，展开选择器后隐藏重复提示。未知身份不声称文件已经变化，真实变化仍阻断，不取消身份核验。

选中仅触发本地检查，不等于授权。检查结果区分可分析、分析可用但写入受限、不可用；检查中与不可用时不能提交。提交前重新检查，成功才更新授权基线；正常追问复用当前授权，检测到变化再检查。旧写入不自动恢复，新分析最多续接一次，用户输入及回答保留。

## 安全边界

### 状态提醒单入口（2026-10-08 补修）

正式 Excel/WPS 共用 `TargetScopeNotice`，移除“暂不操作”与独立“重新检查”，四种提醒原因都只保留“检查数据范围”。原“暂不操作”仅清空提示和待续回调，未改变授权基线，之后监测可能再次显示相同提醒；新提醒没有这个清空动作。不点击时保持阻断，需求/回答保留；点击仅打开既有选择器，打开或关闭都不等于授权。核验并确认成功后才续接新分析，旧写入不自动重放。

真实换文件/表时补充原范围与当前范围名称，私有路径/身份不显示；未知身份不冒充已变化。独立 WPS 面板没有选择器时的兼容确认组件未改。本批未改变守卫触发条件，不宣称解决浏览其他表与任务绑定之间的全部时序问题。

定向验证：共享组件 8 项、Excel 实际发送链路 5 项、授权 hook 42 项、WPS 实际面板 114 项通过。新增断言先复现原提醒多按钮与范围明细缺失，再修复生产代码；双端集成证明忽略提醒不清空输入、点击不直接分析、选择器确认后只继续一次。真实宿主仍待验证；刷新两端前端即可，无协议/后端变更。

单入口补修全量回归：Excel 885、WPS 567、core 311 项通过；后端 1177 通过、1 跳过（不计通过），双端构建和 compileall 通过。保留既有 React act 与 WPS bundle 体积告警，未操作真实宿主、未提交或打包。

### 选择器状态精简与刷新（本轮补修）

正常状态改成一行“已选 N 张表 · 可分析”，移除摘要中的“重新检查”按钮、重复的授权说明及大块状态背景。已知保护、只读和无法核实仍显示具体原因；写入能力未知不冒充已证实的写入限制。统一通过原有“刷新”重读目录并重新校验，即使名称/会话不变也不能复用旧检查结果。

WPS 的顶部当前文件卡片和底部“当前表”使用同一份元数据快照，不再混用宿主探测与已提交索引；打开/刷新自动模式时更新草稿，手动选择保持原样。刷新不得发布新授权或静默删除缺失项，失败后禁用确认且不回显宿主异常。Excel 刷新同样不将手动草稿设为已授权；需要表格上下文的消息不能将未确认的新手动范围自动提交，普通聊天仍不读表。

本轮没有新增持续轮询或扩展读取权限；发送/确认前的真实宿主校验保留，选择器中的信息是最近一次打开/刷新时的元数据。只需刷新两端前端，本补修未更改后端接口。实际宿主仍需验证切表、刷新、取消与确认的时序。

补修回归：Excel 879、WPS 567、core 311 项通过；后端 1177 通过、1 跳过（不算通过），双端构建与 compileall 通过。新增 12 项涵盖紧凑状态、未知写入状态不误报已受限、刷新失败关闭、同目录刷新重试、两处当前表一致、草稿不提前提交及零字段读取。既有 React act 与 WPS bundle 大小告警保留；未进行真实宿主操作。

- Office 使用文档引用、私有路径身份和稳定表 ID；选择器可见目录绑定打开时的身份，不能拿旧列表确认同名新文档。仅读宿主元数据属性，不读单元格。
- WPS 保留弱包装对象的既有证据语义，不能把对象 unknown 当成强相同。选择器不读取 Selection 值；宿主写入版本门、原表保护、预览和确认守卫保留。
- 文件夹 `/api/folders/admission` 仅接受已登记会话、文件 ID 和选中表名，返回封闭状态与指纹。不接收路径、数据行或代码，不修改 session 的已授权来源/目标。文件哈希读取字节，XML 只提取名称/关系/保护元数据属性；不会把文本作为业务数据对象或发给模型。DTD/外部实体拒绝，元数据预算由配置限制。
- 已知只读、锁定、保护和目录限制前置展示。检查不是外部文件锁或永久权限：确认、计划和执行入口继续各自复核。openpyxl 不遵循 Excel 保护机制，已有目标的保护/不可写在计划预检中显式拒绝；拆分汇总仅仅读源表的场景不被误拦。
- 所选项缺失不得自动移除后确认；迟到异步结果不得授权后来选中的目标。报告与宿主对象仅存在当前内存，关闭/重载不恢复弱许可。

## 实机待验与未实现

重启 Python 本地服务（新增接口），刷新 Excel/WPS 加载项。在独立测试文件执行：

1. 不变更文件/表，确认范围后连续追问，不应再有重复目标弹窗。
2. 变更文件或授权表，旧任务暂停；只在原入口检查与确认，原输入和答案仍在，确认后只开始一次新分析。
3. 选择只读、受保护、损坏或刚删除的目标，选择器立即显示原因；不可用时不能提交，受限时不能绕过写入保护。
4. 检查中换文件、删表或切换勾选，不得采用旧结果。暂时无法核实只提示重查，不冒充已换文件。
5. 写入仍须独立生成预览、确认并执行；范围确认不会触发旧写入。

本轮未操作真实工作簿、未调用付费模型、未提交或打包。WPS 文件夹入口仍未实现，不能标记双端文件夹能力对齐；跨关闭强身份和持久私有规则恢复也不是本轮功能。仅修改选择/分析授权交互，未开启隔离 Python 产品开关。
