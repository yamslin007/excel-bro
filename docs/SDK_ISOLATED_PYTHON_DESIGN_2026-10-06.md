# Excel Bro：隔离 Python 分析设计

日期：2026-10-06。状态：用户已批准设计例外；执行器、工具、接口和双端入口均未实现，运行权限未开启。本文描述目标，不是已交付能力，也不是安装或付费请求授权。

## 1. 开放什么

允许模型根据任务自由编写 Python 分析代码，使用预装分析库、多轮试验和任务内中间结果，不限定为几个预设查询。执行只能发生在经过验证的隔离环境中，结果只能由可信适配层接入既有预览与写入机制。

不开放 SDK 内置 Bash/Read/Write 等宿主工具、不允许任意系统命令、VBA/宏、工作簿句柄或直接修改文件；不以“Python 可以分析”推导“所有数据都可以给模型”。普通模型后端与 SDK 共用这项工具能力，不能把 SDK 当成更高权限模式。旧文档的准确率、工期和“安全已完成”承诺不作为依据。

## 2. 最小架构

```text
模型（语义/生成代码）
    ↓ run_python_analysis（显式白名单工具）
可信协调器（核对任务、授权与数据句柄）
    ↓ 仅本次授权数据，固定 IPC
隔离 Python 工作进程（无凭据/联网/宿主目录/工作簿接口）
    ↓ 不可信结果
本地结果库 → 本地审阅 → 白名单 AnalysisPlan → 用户确认 → 宿主执行/回读
    └→ 模型出口策略（默认不发送值；独立出站授权或可信投影）
```

协调器与沙箱必须隔离，不能把 FastAPI 进程、模型 Key、恢复账本或 Office/WPS 对象交给工作进程。SDK 的 cwd、工具权限和会话目录是调用配置，不构成 Python 安全沙箱。

## 3. 数据与授权分离

### 当前目标的绑定

数据由 Excel/WPS 的可信宿主读取适配器提供，使用本任务的工作簿身份、工作表身份、授权版本、范围和源指纹绑定。`datasetHandle` 是任务内不透明引用，不是路径，不能跨任务/会话复用或由模型构造。句柄所属任务、权限版本、来源版本每次都验证；范围增量也必须在用户已选工作表与授权范围内。

本地工具可以按确定性规则读取、计算和构造快照；模型负责语义、决定分析方法与生成代码。代码只能接收经适配器交付的数据对象，不能调用宿主 API、追加表名扩大读取，或按 `sourceFile` 打开文件。文件夹模式只读用户明确选择的文件/表 ID；当前工作簿模式不读磁盘文件冒充未保存的现场。

目标身份确有变化时，先暂停并展示原目标/当前目标，用户明确确认后再读取；答案与授权动作分别保存。正常包装对象变化不能被当成必然换簿，也不能用文件名相同作为身份一致证据。新授权使旧句柄与旧预览失效，不自动继承写入确认。

### 本地计算授权不等于模型出站授权

默认只允许授权数据送入本机隔离执行器，不发送源值、样本、Python 值结果、公式、完整路径给模型。意图阶段仍只使用允许的结构摘要。Python 工具状态和允许的结构信息由可信代码生成，不直接使用 Python 的自由文本。

Python 输出的聚合数、字段内容、摘要、stdout、异常和图像都可能包含或编码原数据，不能因名称为“摘要”就自动出站。若任务确实需要模型解释数据相关结果，先由双端结构化界面展示接收模型/供应商、具体数据或结果类型与范围、用途，再获得独立出站授权；不预勾选，不把本次用户的 Python 许可当作同意数据上传。无出站授权时模型可生成方法和代码，结果留本地给用户查看；不能假称模型已看过数据并作出结论。

固定可信摘要器可依已批准的字段/操作生成受控投影，但不能把任意 Python dict 包装成“可信摘要”。摘要器与出站策略均在沙箱外，不允许代码修改。数值也可能是敏感结果，隐私判断不能只靠文本脱敏或哨兵匹配。授权的上传也仍不得越过工作表边界或带入密钥、未授权表等内容。

现有服务地址可配置，不能假定它永远在本机。新增数据投递只接受经过验证的本机执行器连接，不跟随任意远程 API 地址、重定向或供应商端点；要支持远程计算必须另做设计并获得明确授权，本设计不包含它。

## 4. 真隔离的必要条件

实施时先核对目标 Windows 部署能力，选择可实际提供下列隔离的 OS/虚拟化方案并记录官方依据与实测。本文不预先宣称任意 Windows、容器配置或 SDK 默认沙箱支持全部条件。不安装运行环境或启用后台服务来绕过缺失条件。

- 工作进程没有网络访问能力，不能连接互联网、局域网、回环服务或模型端点；网络禁令必须由环境强制，不是提示词或 monkeypatch。
- 只读受控输入和预装运行库；不能挂载仓库、用户目录、真实工作簿、配置、SDK 会话、缓存或恢复账本。临时写入只在隔离 scratch 内，有大小上限与清理策略。
- 不继承模型/API Key、宿主凭据或任意环境变量；不能读取宿主进程环境、访问 Office/WPS COM 或操纵 UI。运行器不能接受用户指定宿主可执行文件/命令行。
- 外部程序执行和派生进程受环境禁止；运行时若有内部进程，限于经过验证的固定启动链。不能从 Python 运行 PowerShell、cmd、shell、pip 或安装库。
- CPU、内存、进程/线程数量、墙钟时间、输入/输出/scratch 容量在环境与协调器双层有可验证的上限。耗尽、失联、取消或超时要终止整个执行树，确认终止前不能复用沙箱或发布结果。
- 依赖固定版本、预装清单可验证；模型不能运行时下载代码。输入解析器和 IPC 有类型、长度、尺寸检查，不反序列化 pickle 或 Python 对象到可信进程。
- 路径穿越、符号链接、环境变量、反射、动态 import/原生扩展等不能绕过宿主隔离。AST/禁词可以做诊断或缩小能力，但不能充当安全边界。

运行器缺失、隔离配置错误、健康检查不通过或资源限制不能落实时，返回固定的“隔离 Python 不可用”，工具不能在宿主 `exec`、同用户子进程、venv 或临时目录里继续。实现可在沙箱内运行生成代码，禁止的是在可信进程中裸执行。SDK 仅列入准确 MCP 工具名，不开启通配符工具权限。

既有可信程序对 Excel 的白名单操作仍可执行；这不把同类 COM 权限授予 Python。隔离方案需要对目标版本逐一验收，不宣称绝对无侧信道或所有平台通用安全。

## 5. 工具与结果契约（待实现）

以下名称是设计建议，不是已有 API/字段。实施前结合现有源码确定版本、大小限额和完整联合类型，并同步 TS/Python 契约。

- `run_python_analysis`：协调器生成/核对 `taskId`、`operationId`、授权版本；模型可提供代码和本任务已获准的数据句柄。请求禁止路径、命令行、包安装指令、宿主对象或供应商密钥。代码长度、累计读取/运行额度统一放 capabilities 配置。
- 工具回执：使用固定状态、运行 ID、本地结果句柄及允许的元数据。执行失败只返回安全错误类别；原始 stderr/traceback 留受控本地诊断，不直接发模型或聊天历史。
- 本地结果：矩阵/图表或分析输出作为不可信数据保存在任务生命周期内，带源版本与授权绑定。不把完整矩阵嵌入恢复描述、HTTP 规划请求或 SDK 工具文本；前端查看和模型接收是不同通道。
- `resultHandle`：随机、任务内、短期、不可跨授权版本。取消、目标变化或会话结束失效。句柄不是默认可在任意模型请求中解引用的数据读取权限。
- 结果到计划：可信适配器检查尺寸、类型、坐标、目标授权、公式/文本语义与宿主能力，只编译成现有白名单 `AnalysisPlan`。防止字符串被 Excel/openpyxl 自动当成公式；公式须走明确且已验证的公式动作。无合法动作时显示本地分析结果，不伪造写入支持。

修复 SDK 非终结结果时，只有新增/已批准工具的有类型投影能返回；不得把 `_execute_tool` 的任意 dict 直接 `json.dumps`，也不得无差别删除 `planningReadPolicy`、`dataResults` 等隐私守卫。现有 `ifNeeded`/`none` 契约不接受未定义的 `structure` 值。新增能力应单独建模、校验，兼容旧客户端。

需要回写时，在本地可信边界重建计划与验证材料，不把含敏感值的本地计划发送到远程计划校验接口或完整持久账本。若现有接口不能表达本地句柄，先做版本化协议变更，不能把矩阵塞进原字段规避边界。

## 6. 多轮探索、取消与恢复

同任务内允许 Python 多轮分析与修正，结果句柄维持数据版本。可复用的沙箱也必须验证清理与任务隔离；不能跨任务保留旧输入、全局变量或文件。资源限额控制整个任务累计使用，不只限制单次调用。合理资源保护不能以“解除模型预算”取消。

任务进度由真实协调器事件产生，分清排队、分析、结果可审阅与等待写入确认；不展示模型内部思考文本。用户取消时先停止数据交付和发布，再终止执行树，迟到响应不得生成可执行计划。网络重试使用运行 ID 查询真实状态，不自动重复启动未知运行。

重启后内存结果不可用时，明确显示“重新读取并分析”，重新核对授权与数据、重新预览，不声称精确续跑。恢复描述只保留必要身份摘要、授权版本、范围、状态、指纹与进度，不保存值矩阵、原始输出、带数据字面量的代码或模型转录。本方案不新增 SDK 会话持久化，不改变 `--no-session-persistence`；未来续跑能力另做隐私与恢复设计。

分析执行状态与工作簿写入状态分开。原表写入途中结果未知时沿用现有核对流程，不能为了重跑 Python 把 `unknown` 变成 `not_written`。全部写入已完成而回执丢失时只核对/补回执，不能重写。

## 7. 用户交互与双宿主对齐

Excel/WPS 使用相同的 Python 分析开关、授权含义和进度语义。工具不可用时说明缺失条件，不循环询问业务规则，不自动打开任意权限。目标变化的确认在开始读取/分析前完成；只有实际数据或语义有缺口才发起结构化澄清，已回答的问题按 questionId 保留/替换。

入口流程：确认任务目标与选表 → 隔离就绪检查 → 当前授权范围读取 → Python 分析 → 本地结果/副本预览 → 用户确认 → 既有白名单执行与回读。需要模型接收数据时在出站前单独授权；不合并为一个默认勾选框。纯分析任务无需强加写入确认，但不能因此跳过数据授权。

两端共享协议、工具语义、隐私投影和计划编译；宿主读取、原生副本与写入适配保留差异。不能为 WPS 假造动作、扩大授权或把 Excel 行为称为 WPS 已实现。文件夹模式使用明确 ID 的可信只读适配，不让代码拿到文件系统句柄。

## 8. 实施顺序

1. 源码复核：工具注册/权限、SDK 非终结返回、数据读取、模型/HTTP 出口、预览、执行、存储与恢复；列出真实缺口，不沿用历史完成汇报。
2. 隔离原型：纯合成输入，选定目标 Windows 方案；先证明越权、联网、资源耗尽、取消和不可用拒绝。未通过不接真实数据、不启用功能。
3. 共享契约/可信协调器：任务内句柄、授权绑定、输入输出验证、本地投递、模型投影和生命周期；默认关闭，配置限额集中管理。
4. 普通后端与 SDK 同语义接线，Excel/WPS/文件夹可信适配及结果预览；不改现有模型配置，不自动切供应商，不修饰旧 SDK 能力为已完成。
5. 双端自动化、真实沙箱集成、完整回归；再在获准的独立测试工作簿实机验收。需要安装/启用运行环境或付费模型请求时先说明并获取授权。

## 9. 验收证据

| 范围 | 必须证明 | 不可替代证据 |
|---|---|---|
| 真隔离 | 越权读文件/凭据、网络/回环、外部程序与逃逸测试被环境拒绝；运行器缺失零裸执行 | cwd、venv、禁词、mock、配置截图 |
| 生命周期 | 资源上限、超时/取消整个执行树终止、迟到结果拒绝、跨任务无残留 | 只测父进程退出 |
| 隐私 | 合成哨兵确在本地数据/结果；真实 fetch、模型消息、SSE、日志/存储/账本/SDK 出口无未获准敏感内容 | 只测投影 helper 或空输入 |
| 输出攻击 | stdout、错误、摘要、嵌入数据的代码分别被出口策略拒绝；数值摘要也需策略 | 只搜索一个字符串 |
| 授权 | 跨任务句柄、范围扩大、换簿/换表/授权版本变化被拒绝；读后与写前再次核对 | 相同文件名或一次读取 |
| 宿主写入 | 两端实际按钮走到预览；确认前新增写入为 0；取消/冲突为 0；确认后仅白名单计划执行且独立回读 | 同款 UI 或单端绿灯 |
| 恢复 | 句柄丢失重新分析的真实文案；未知写入不重放；回执补记零新增写入 | “可以继续”无真实点击链路 |

隐私用例先断言本地哨兵存在，且真实边界请求被实际捕获，避免空过；无需真实客户数据/Key。分别拆掉隔离失败中止、出站投影、句柄授权绑定、预览确认和取消结果门等守卫，测试应独立变红；还原后回归。变异证明断言有判别力，不证明沙箱本身安全。

代码实施按 AGENTS.md 跑双端 test/build、服务端全量 pytest 与 compileall，改 core 加 test:core。分别报告通过、失败、环境阻断、未实现与实机待验；跳过真实隔离集成就是隔离未验证。当前无可验收运行器，不填“已完成，仅待实机”。
