# EB 函数系统 - 规则管理界面完成

## ✅ 新增内容

### 规则管理组件 (RuleManager.tsx)

完整的可视化规则管理界面，支持：

#### 核心功能

1. **规则列表显示**
   - 分类显示：预制规则 / 自定义规则
   - 规则卡片：名称、描述、示例公式、依赖关系
   - 只读标记：预制规则不可删除

2. **搜索过滤**
   - 实时搜索规则名称和描述
   - 支持中文搜索

3. **刷新所有 EB 函数**
   - 按拓扑排序刷新
   - 循环依赖检测
   - 刷新进度显示

4. **删除规则**
   - 依赖检查：显示哪些规则依赖当前规则
   - 二次确认
   - 预制规则保护

5. **导入/导出**
   - 导出为 JSON 文件
   - 从 JSON 文件导入
   - 重复规则跳过

6. **统计信息**
   - 总规则数
   - 预制规则数
   - 自定义规则数

#### UI 特性

- **模态框设计**：半透明遮罩 + 居中弹窗
- **响应式布局**：最大宽度 800px，高度 90vh
- **消息提示**：成功/错误消息自动消失
- **状态管理**：加载状态、刷新状态
- **交互反馈**：悬停效果、选中状态

## 🔗 集成方式

### 方式 1：顶部工具栏按钮

```tsx
import { RuleManager } from './RuleManager';

// 在 App.tsx 中添加
const [isRuleManagerOpen, setIsRuleManagerOpen] = useState(false);

// 按钮
<button onClick={() => setIsRuleManagerOpen(true)}>
  ⚙️ EB 规则
</button>

// 组件
<RuleManager
  isOpen={isRuleManagerOpen}
  onClose={() => setIsRuleManagerOpen(false)}
/>
```

### 方式 2：工具抽屉入口

在"我的工具"标签页添加链接按钮
