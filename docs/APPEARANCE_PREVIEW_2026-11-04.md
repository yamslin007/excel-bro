# 壁纸与外观：实时预览

## 已实现

Excel 和 WPS 共用 ThemePanel、useTheme、appearanceSettings 和最后加载的 appearance.css。移除边调边保存：打开设置建立草稿，调节同时更新窗格与示例预览；取消、关闭、Escape 或离开面板恢复原外观。应用成功才关闭，保存失败保留草稿并说明原因。

- 清晰办公、轻透玻璃、突出壁纸三种预设，可继续微调。
- 壁纸：上传/更换/删除、填充/适应、100–200% 缩放、拖动或滑块定位、亮度、模糊、浓度和遮罩。
- 卡片：底色浓度、模糊和圆角；输入框保持较实底色，用户消息采用浅底深字。
- 配色：原四套主题、自定义主题色、浅色/深色/跟随系统。深色模式调亮主题前景。
- 数值输入和单项重置；恢复默认也属于草稿，可以取消。
- 宽窗格左右布局，宽度不超过 740px 时上方固定预览、下方滚动调节。底部操作固定，键盘焦点限制在弹层内，关闭后恢复焦点。

示例预览不复制聊天、不调用模型或宿主。实际窗格采用同一组 CSS 令牌，不依赖 color-mix；不支持 backdrop-filter 时退为实色底。图片保存在各自浏览器来源的本机 IndexedDB，没有新增跨 Excel/WPS 同步或网络上传。未变更授权、执行、回读、审阅、放弃或撤销，也未操作真实工作簿或提交 Git。

## 保存与兼容

保留原 IndexedDB、旧图片及预设/浓度/遮罩，新字段经过默认值补齐和范围校验。打开面板不会写回配置，也不会静默删除读取失败的旧数据。

saveThemeSnapshot 在同一事务写图片和配置，等待事务完成才报告成功。上传有版本号隔离，取消、重开、删除或恢复默认后，迟到的图片不覆盖当前草稿。上传期间禁止应用；保存期间禁止重复应用或修改。临时 object URL 随图片生命周期释放。
