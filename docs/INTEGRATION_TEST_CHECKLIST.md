## 场景 1：基础对话流程（30 分钟）

- [x] ⚠️ **已知问题**：2 轮后选"我不知道"，系统会自行判定操作（可能选破坏性动作）

## 场景 2：工具管理（20 分钟）

> **重要：** 工具不能凭空新建，必须先执行成功一个流程，再从执行结果保存为工具。

### 2.1 从执行结果保存为工具

- [ ] 发送一个能生成计划的指令（如"汇总 Sheet1 的销售额"）
- [ ] 预览计划 → 点击"执行到 Excel"，等待执行成功

- [ ] 补写工具名称、描述后保存

> **注意：** 工具只能从工具抽屉点击运行，对话里说"运行 XX 工具"无效——工具列表不进入模型上下文。

- [ ] 打开工具抽屉，点击已保存的工具
- [ ] 进入运行视图，显示参数表单

- [ ] 点击执行，生成计划并预览
- [ ] 执行到 Excel，结果正确
- [ ] （可选）换一份结构相同、数据不同的表再跑一次，验证存的是流程而非固定结果

### 2.3 查看工具详情

- [ ] 工具列表点击某个工具，进入详情页

## 问题记录

### 问题 1：澄清耗尽后选破坏性操作

**现象：** 输入"把数据整理一下"，两轮澄清后选"我不知道"，系统自行判定为去重删除行。

**严重性：** 中（有预览拦截，但依赖用户读懂说明）

**复现步骤：**
1. 输入"把数据整理一下"
2. 第 1 轮澄清选"按原话继续"
3. 第 2 轮澄清选"我不知道"
4. 系统生成删除重复行的计划

**根因：** `server/app/intent.py:46-47` 兜底规则未区分「需求明确的写入」与「需求模糊的写入」

**是否阻塞发布：** 否（预览机制能拦截）

---

### 问题 2：切换对话后撤销按钮残留 ✅ 已修复

**现象：** 执行操作后新建对话，撤销按钮仍显示

**严重性：** 高（可能撤销错对话的操作）

**修复：** 撤销按钮改为只在执行结果消息下方显示，移除输入框全局按钮；补全 `executedPlanId` 设置

**提交：** cfcac69, a20b03b

**验证：** ✅ 通过（执行结果消息下方出现撤销按钮，输入框无残留，功能正常）

### 问题 3：单字符消息返回原始错误 ✅ 已修复

**现象：** 输入"1"发送，返回 JSON 格式的 Pydantic 错误

**严重性：** 低（体验问题）

**修复：** 发送前检查 `text.length < 2`，静默拦截

**提交：** 1417183

**验证：** ✅ 通过（单字符静默拦截，两字符正常发送）
