# Excel/WPS 图片附件接入

两端均支持选择、粘贴、拖入 PNG/JPEG/WebP，预览、删除和仅图发送。
处理复用 `useImageAttachments` 与 `prepareImageFile`：数量、源文件大小、压缩后大小和
最大边长来自 `config/capabilities.json`。处理期间保留名额并阻止发送；清空或切换对话
会废弃旧的异步结果，避免旧图片回到新对话。

## 出站与授权

- 添加文件只做本地解码和压缩；用户发送前不会调用模型。
- 工作簿/工作表授权仍先于需求分析，图片不能扩大授权范围。
- 意图请求只含 `imageCount`，不含图片字节及表格数据行。
- 规划请求使用既有 `PlanRequest.images` 和 Python `ImageAttachment` 契约，无协议增项。
- OpenAI-compatible 发送 `image_url` data URI；SDK 发送异步 user 消息中的 Anthropic
  `image/source/base64` 块。两者仅处理用户主动添加的图片，不截屏或导出工作簿。
- SDK 不上传工作簿数据行，不开放内置文件/命令工具；`--no-session-persistence` 禁止
  本次 CLI 会话转录落盘。上传后的服务端/供应商处理仍遵循其既有请求和保留策略，
  不能把“本地聊天不存图”当作“服务端和供应商不保留图”的承诺。
- 图片内容仅在前端输入框及同任务续答内存保留，历史只含附件名称/需要重新附图的标记。
  规划失败保留附件；面板重开、切换对话后缺图的任务需重新添加，不能静默按无图继续。
- 图片中的文字是输入材料，不是新的系统权限。写入仍必须白名单计划、预览、用户确认。

## 模型配置

不要按供应商名猜测视觉能力。独立连接通过既有“支持图片输入”配置，
环境模型使用 `AI_VISION_MODELS`；SDK 派生连接继承明确配置的能力。
独立 Anthropic SDK 环境选项新增 `CLAUDE_AGENT_SDK_SUPPORTS_VISION=true`，
默认关闭，需重启后端。若实际模型不支持视觉，勾选能力也不会使其支持。

## 验证

共享 Hook 覆盖并行名额、粘贴、拖放、清空时异步废弃；
Excel SSE/WPS 真实 fetch 请求测试验证意图数量与规划图片字节分离；
WPS DOM 测试验证选择/预览/删除、非视觉阻止发送、澄清点击续答携带原图、
数据行哨兵不出站、本地聊天不存图、宿主写入次数为零。
SDK 假传输验证原生 image 块、结构隐私、非视觉零调用、禁止会话落盘。
这些不是供应商端到端实测；真实 Excel/WPS 文件对话框、截图粘贴与真实视觉模型
仍需独立测试工作簿进行实机验收，本轮不调用付费模型、不操作真实工作簿。
